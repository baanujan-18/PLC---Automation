# Demonstration Video

This video demonstrates the PLC-based Knight Rider LED pattern developed using a Siemens S7-200 PLC.

Eight LEDs are connected to PLC outputs Q0.0 through Q0.7. The LEDs activate sequentially from one side to the other and then return in the opposite direction.
